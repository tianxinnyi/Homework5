# 全局变换演示（Unity 2022.3）

## 运行
用 Unity Hub 打开本目录（包含 Assets、Packages、ProjectSettings 的 hw5 文件夹）。打开 `Assets/Scenes/SampleScene.unity`，点击 Play。程序会自动创建界面和模型，不需要手动挂脚本。

## 操作
- `加载 OBJ`：填写本地 OBJ 文件的完整路径，点击按钮加载。默认自动加载随项目附带的 cc.obj。
- Unity 编辑器内也可点击 `浏览 OBJ 文件...`，使用文件选择框导入。
- `锥化`：沿 Y 轴从底部向顶部改变横截面缩放。
- `扭曲`：沿 Y 轴按高度改变旋转角度。
- `弯曲`：沿 Y 方向按圆弧弯曲。
- `变形强度`：实时调节前三种变形的强度。
- `复原`：恢复原始模型，保留 FFD 控制点编辑；`重置控制格` 恢复 FFD 初始状态。
- `FFD 控制格`：显示控制点及连接线。选择 n=2、3、4 或 5，生成 n×n×n 控制格（改变 n 会重置控制点）。
- FFD 的点编号滑条选择控制点；黄色较大的点为选中点；X/Y/Z 滑条修改该点的位置并实时观察模型变化。默认 3×3×3，可先选择 26 号角点并调整 X，观察清晰效果。
- 在右侧模型区域按住鼠标左键拖动可环绕观察，滚轮缩放。

## 算法与实现
`GlobalTransformDemo.cs`：运行时 OBJ 解析、网格细分、三种全局变换及 FFD。`LatticeView.cs`：控制点与控制格的运行时可视化。

FFD 首先对导入模型计算轴对齐包围盒，模型居中后等比归一化至最长边为 2；控制点初始位置为包围盒各轴的均匀采样。顶点映射至包围盒参数坐标 (u,v,w)，用 n-1 次三维张量积 Bernstein 基函数对控制点加权。改变控制点后重新计算所有顶点；原始规则控制格使模型保持不变。

附件金字塔仅有 5 个顶点，因此导入低面数模型时细分三角面，确保连续扭曲、弯曲与 FFD 有可见效果。高面数模型不进行额外细分。顶点变形后重新计算法线和包围盒。

OBJ 导入支持 v、f、v/vt、v//vn、v/vt/vn、负索引和凸多边形扇形三角化；使用统一演示材质，不读取 MTL/贴图，凹多边形应先在建模软件中三角化。目标为 Unity Editor 和 Windows 桌面构建；默认模型放在 StreamingAssets 中以随构建复制。
